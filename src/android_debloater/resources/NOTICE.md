# Catalog and font sources

The bundled package descriptions are original, generic summaries written for
Android Debloater. An earlier Samsung audit supplied candidate package IDs and names. Its personal selections, recommendations, and removal
history were not imported. No text from the audit's UAD reference catalog is
redistributed in this application catalog.

Generic Android behavior was checked against the Android documentation and
package-manager source below. Descriptions are not a safety guarantee.

- Android ADB: https://developer.android.com/tools/adb
- Android package manager: https://android.googlesource.com/platform/frameworks/base/+/main/services/core/java/com/android/server/pm/PackageManagerShellCommand.java

IBM Plex Sans comes from the Google Fonts distribution of IBM's font.
The unmodified variable font and SIL Open Font License are in static/fonts.
Source: https://github.com/google/fonts/tree/main/ofl/ibmplexsans
